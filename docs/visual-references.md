# Battlefield visual references

The Three.js battlefield is an original, simplified game model informed by
Bhutanese architectural references. It does not copy a photograph or claim to
reconstruct a particular dzong exactly.

- [Bhutan Tourism, Culture and Architecture](https://bhutan.travel/experiences-culture): whitewashed, inward-angled dzong walls, a red upper band, a fortified entrance, a central utse, and an open courtyard.
- [Bhutanese Architecture Guidelines, Ministry of Works and Human Settlement](https://www.mowhs.gov.bt/wp-content/uploads/2010/11/Arch-Guidelines-FINAL-14OCT-2014.pdf): pages 21–23 show dzong layouts and the utse; pages 114–125 describe timber rabsel window galleries, their cantilevers, and bracket details.
- [Punakha Dzong photograph by Nihar Modi, Unsplash](https://unsplash.com/photos/brown-and-white-concrete-building-near-green-trees-and-lake-during-daytime-uMbGXBy7bKs): reference for the overall massing and layered roofs. A local 1800-pixel version is used on the main menu under the Unsplash License.
- [Traditional rabsel window photograph, Mandala Collections](https://images.mandala.library.virginia.edu/image/window-rabsel-bhutanese-traditional-house): reference for timber-framed upper windows.

The scene uses five locally stored 1K textures from [Poly Haven](https://polyhaven.com/), licensed CC0: [grass ground](https://polyhaven.com/a/grass_ground), [stone floor](https://polyhaven.com/a/stone_floor), [white stucco](https://polyhaven.com/a/white_stucco), [dark wood](https://polyhaven.com/a/dark_wood), and [roof planks](https://polyhaven.com/a/roof_planks). They are bundled in `web/assets/materials/`, so only the Three.js module itself loads from a CDN.
